# Student Record Management System

A console-based Student Record Management System developed in C.

This project allows users to add, view, search, update, delete, sort, and manage student records. It also provides student statistics and automatically saves records to a file.

## Features

- Add new student records
- View all student records
- Search student by roll number
- Update student information
- Delete student records
- Sort students by:
  - Marks
  - Name
  - Roll number
- Calculate student statistics
- Calculate grades automatically
- Prevent duplicate roll numbers
- Validate marks between 0 and 100
- Handle invalid user input
- Save student records to a file
- Load records automatically when the program starts

## Technologies Used

- C Programming Language
- GCC Compiler
- Visual Studio Code
- File Handling
- Structures
- Arrays
- Functions
- String Handling
